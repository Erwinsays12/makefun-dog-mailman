Entry for the [make.fun](https://make.fun/c/u-motasimfuad-the-dog-reviews-the-mailman-87608f85) competition **"The Dog Reviews the Mailman"**: write one funny one-line review a dog gives the mailman, under 200 characters.

## What it does

`main.ts` writes a single fixed, deterministic review to `/output/entry.txt` — the champion of a 12-candidate pool judged head-to-head against the competition's own rubric (dog's voice, the mailman's visit, the punchline):

> Five stars. He comes every day, knocks twice, and still hasn't learned the mail slot is MINE. I allow him to live.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network, no input — the same 114-character review is produced on every run.
